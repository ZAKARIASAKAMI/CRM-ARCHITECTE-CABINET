# CRM Architecte Cabinet - Frontend

Application frontend React (Tailwind CSS) pour le CRM du cabinet d'architecture.

## Getting Started

1. Install Dependencies
```
npm i
```
2. Run the development server:

```bash
npm run start
```

3. Build for production:

```bash
npm run build
```

## Backend

L'API tourne par defaut sur `http://127.0.0.1:8000/api` (voir `src/services/api.js`).
